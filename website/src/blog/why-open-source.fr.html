Pensez à tout ce qui passe par votre application e-mail en un an. Des contrats, des factures, des résultats médicaux, les réinitialisations de mot de passe de tous vos comptes, et ce que vous ne dites qu’aux personnes de confiance. Aucun autre programme de votre ordinateur ne voit autant de votre vie.

La plupart des applications e-mail vous demandent de les croire sur parole pour ce qu’elles en font. Pas Regards. Chacune de ses lignes est publique, et voici pourquoi.

Une confiance que vous pouvez vérifier

Une politique de confidentialité est une promesse. Le code source est un fait. Quand nous disons que vos e-mails circulent entre votre ordinateur et votre fournisseur, et nulle part ailleurs, vous n’avez pas à nous croire : le code qui ouvre chaque connexion est là, lisible. L’absence de tout le reste aussi. Il n’y a aucune télémétrie dans Regards, et aucun serveur à nous qu’il pourrait appeler.

Vous n’en lirez peut-être jamais une ligne. Cela vous protège quand même, parce que tout le monde le peut : les chercheurs, les journalistes, les concurrents, les curieux. Une application qu’on peut inspecter à tout moment doit bien se tenir à tout moment.

Cela compte double quand une IA s’en mêle

Regards laisse votre agent IA travailler dans votre boîte : lire, classer, rédiger, et envoyer une fois que vous avez approuvé. C’est beaucoup de pouvoir à confier, et « faites-nous confiance » ne suffit pas comme réponse.

L’interface des agents est ouverte comme le reste. Vous pouvez voir exactement ce qu’un agent a le droit de faire à chaque niveau, que l’envoi vous attend toujours, et que chaque action est enregistrée et peut être annulée. Les limites sont dans le code, où on peut les vérifier, pas dans une brochure.

On ne peut pas vous retirer votre application e-mail

Les applications sont rachetées, changent de prix, se remplissent de publicités ou ferment. Quand cela arrive à une application fermée, ses utilisateurs n’ont pas leur mot à dire.

Regards est publié sous les licences Apache-2.0 et MIT, qui donnent à chacun le droit de l’utiliser, de le copier, de le modifier et de le partager, pour de bon. Il n’y a pas de compte chez nous à fermer, ni de serveur à nous dont votre exemplaire dépende. Si nous arrêtions demain, le Regards que vous avez continuerait de fonctionner, et n’importe qui pourrait prendre la suite.

Gratuit, et franc sur le pourquoi

Regards ne coûte rien : toutes les fonctions, toutes vos adresses, sans essai, sans publicité. Il peut être gratuit parce qu’il n’a pas de serveurs à payer. C’est votre ordinateur qui travaille, et pour l’IA vous branchez l’agent que vous avez déjà.

Un service payant, facultatif, est prévu pour la version 1.1 : l’envoi quand votre ordinateur est éteint, qui demande bel et bien un serveur. L’application elle-même reste gratuite, et reste ouverte.

Développé au grand jour, pas seulement publié

Open source peut vouloir dire un tas de code jeté par-dessus un mur. Nous voulons dire plus que cela.

  • Les décisions sont publiques. Pourquoi Regards est construit ainsi est écrit dans le dépôt, une décision à la fois.
  • Les mesures sont publiques. Quand nous disons que Regards est rapide, le test et ses résultats bruts sont là, y compris la ligne que nous perdons.
  • Les erreurs sont publiques. Les bugs sont signalés, discutés et corrigés là où tout le monde peut voir.
  • La porte est ouverte. Signalez un problème, demandez une fonction, ou proposez une modification. Voici comment contribuer.

Lisez-le, compilez-le, modifiez-le
